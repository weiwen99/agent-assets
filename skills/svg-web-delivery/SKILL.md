# SVG 网页交付

从已有图源交付可读的网页 SVG。固定底色与主题自适应是两条分支：保留可编辑主源及固定底色制品，按目标生成网页衍生版。本技能不代替绘图，也不授权发布或修改网站。

## 前置

- 确认图源、交付页面、编辑权限与需要保留的制品；目标不明时先问，不把“HTML 支持 SVG”当成必须透明化。
- 完整读取 [网页约定](references/web-contract.md)。自适应分支还要查看 [最小 SVG](fixtures/theme-aware.svg) 与 [宿主示例](fixtures/index.html)；这是合成示例，不是通用转换器。
- 本目录可独立安装。绘图调用方与它同在一个 skills 根；缺依赖时从 `https://github.com/weiwen99/agent-assets` 整仓取用到可写工作区，记录 commit，读取完整目录及引用材料。取用不等于机器安装或运行时升级。

## 步骤

### 1. 选定交付分支

记录固定底色或主题自适应。印刷、未知宿主、指定纸面配色可以继续交付固定底色 SVG；需要融入网站明暗主题时才选择自适应。固定分支沿用绘图技能的底色、PNG/PDF 与视觉检查，第 3 至 4 步记不适用。
完成条件：每份图有目的地、分支和可编辑主源；没有把所有 SVG 归为透明图；无自适应任务时明确写明。

### 2. 固定源与绘制清单

保留源文件及原始输出，记录 hash 或版本。清点文字、路径、变换、线宽、点径、箭头 marker、图层和有意义的白色区域。TikZ 保留 `.tex`，字形路径化是导出策略；Inkscape 保留活文字、语义 ID 和编辑图层，衍生时可以增加必要的遮罩分组。
完成条件：每个保留对象可在原稿和衍生稿间对应；没有用截图重画或默认将编辑主源转路径；无须衍生时原图保持不变。

### 3. 核对宿主主题约定

自适应分支检查真实嵌入方式、手动主题、系统偏好、资源 URL 与 MIME。外部 SVG 经 `<img>` 加载时，由宿主的 `color-scheme` 提供方案，图内媒体查询负责配色；不假设页面 CSS 变量穿过文档边界。先用本地宿主示例核对反向组合。宿主需改代码而未获授权时，停在待接入，不擅自部署。
完成条件：每种目标主题都有信号来源和选择器依据；没有把本地预览当成真实宿主已通过；固定底色时本步记不适用。

### 4. 生成网页衍生版

按网页约定处理角色配色、透明区域与绘制次序，包含箭头填色、文字和辅助线。只移除已识别的整页底色；标签、空心点、区域填色与白色物体分别判断。遮罩清除早期绘制，保留后画文字。图内同时处理独立打开的根颜色方案与打印浅色覆写；文件名与主源区分。
完成条件：每个颜色角色和遮挡区域有明确处理，几何与内容差异均有说明；没有批量去白底、任意反色或新增外部脚本/字体依赖；固定分支记不适用。

### 5. 验证本地图像

运行静态夹具检查，再在真实浏览器中检查交付图：两种系统偏好乘网站支持的手动主题，至少包含系统浅/页面深及反向组合；桌面与窄屏、独立原图、打印分别核对。查看真实截图而非只读 CSS 或 canvas 重渲染。对比几何/文字清单，检查透明边缘、遮挡、点径和对比度；记录版本及未覆盖项。
完成条件：每张交付图的本地检查都有结果或明确待验项；没有把夹具通过当成任意图通过，也没有把未运行的浏览器/打印检查写成成功；不涉及的分支写明。

### 6. 复核真实目的地

已有获准访问的发布 URL 时，核对匿名详情、所有本次 SVG 的 MIME/字节、实际主题切换、原图链接和打印。普通 Markdown 链接未必和图片一起改写，必须按最终 URL 复查。发布由调用方的发布技能完成；尚未获准发布时，只交付本地结果并列出宿主待验项。
完成条件：每个已发布 SVG 及原图链接都有实测结果；没有以 HTTP 200 或单个角落像素代替整图验收；无发布授权或 URL 时明确标为未发布验证。

### 7. 交接

交付主源、固定底色制品、网页衍生版及重建说明，记录目标分支、宿主要求、已验/未验矩阵和回退文件。清理临时浏览器、截图与试渲染，保留用户需要的版本和文字证据。
完成条件：每个文件有用途及来源，所有差异与待验项可定位；没有把源文件或失败记录随临时物清理；无额外交接时写明。

## 边界

权限与发布流程以使用方仓库和用户指令为准。本技能不自授权编辑主源、放开 HTML 过滤、改变站点样式或部署；不将纯白一律视为透明，不把案例配色/结构识别当成通用 SVG 清洗器，不执行未审核的 TeX 或 SVG 脚本。固定底色与无障碍/品牌色约束优先于自动适配；缺宿主支持或验收证据时保留不足，不声称所有浏览器、WebView、深色插件或强制色模式都已兼容。
