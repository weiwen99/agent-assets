* 关键行为

固定底色SVG仍可在HTML使用，只有需要随主题变化才派生适配版。不改两个既有渲染脚本、模板与白角校验。TikZ保留tex与字形路径；Inkscape编辑主源保留活文字、语义层与ID，遮罩必要分组可增加。

共用技能完整描述宿主只传scheme、图内角色包括marker、白色按语义判断、mask只清早期绘制、独立原图根方案及打印后覆写。案例只是来源，不提交案例配色转换器。依赖读取失败先从公开完整仓取用并记录commit，不把取用说成安装或部署。
